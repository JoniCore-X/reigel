Build a real local-first Python FastAPI + SQLite app, vanilla HTML/CSS/JS. No simulated metrics/messages, no automatic Git commits. Public landing `/`, private app `/app`, static resources `/static/`. All dates API ISO 8601 with offset; business timezone `America/Puerto_Rico` configurable. Multiuser admin/advisor roles. ## Core ownership and API

Core agent owns `reigel/core.py`, `reigel/api.py`, `reigel/__init__.py`, `main.py`, `requirements.txt`, `scripts/bootstrap.py`, `tests/test_core.py`. Root owns other tests/docs/scripts. Connector agent owns `reigel/channels.py`, `reigel/assistant.py`, `tests/test_channels.py`. Frontend agent owns `frontend/` only.

`create_app(db_path=None)` in `reigel/api.py`; `app=create_app()` in `main.py`. `Store(db_path)` in core exposed as `app.state.store`. SQLite connection per operation; WAL, foreign keys, transactions with BEGIN IMMEDIATE for bookings. Admin sees all; advisor only assigned leads, conversations, appointments. Server enforces every private read/write. Password scrypt/PBKDF2 and opaque hashed sessions, HttpOnly SameSite=Strict cookies. Origin check on unsafe private routes (reject foreign Origin), rate limit login/public intake, no credentials in API responses. No default password. Bootstrap script supports `--email --name`, generates random password into ignored `.local-access.txt` (root will launch). Avoid debug stacktraces, restrictive security headers. Private API unauthenticated returns 401.

Endpoints and JSON envelopes (error `{"detail":"Spanish message"}`):

* GET `/health` `{status:"ok", database:true}`; no secrets.
* POST `/api/auth/login` `{email,password}` -> `{user:{id,name,email,role}}` + cookie. GET `/api/auth/me` same envelope. POST `/api/auth/logout` -> `{ok:true}`.
* GET `/api/dashboard` -> `{metrics:{leads,appointments,conversations,conversion_rate}, stages:[{stage,count}], recent_leads:[], upcoming_appointments:[]}`. Leads stages `nuevo,contactado,calificado,cita,ganado,perdido`.
* GET `/api/leads` -> `{leads:[{id,name,email,phone,municipality,monthly_bill,source,stage,advisor_id,advisor_name,consent,created_at}]}`. POST `/api/leads` same editable fields with name required, consent boolean required true if permission to contact; manual CRM can consent false. PATCH `/api/leads/{id}` fields stage/advisor_id/notes (admin only assignment, advisor own lead stage/notes). GET `/api/leads/{id}` -> `{lead:...,appointments:[]}`.
* GET `/api/team` -> `{users:[{id,name,email,role,active,public_booking,timezone,work_start,work_end,work_days,duration_minutes}]}` (advisors see self only). POST `/api/team` admin `{name,email,password,role:"advisor"}`. PATCH `/api/team/{id}` admin or self (self cannot modify role/active), editable public_booking,timezone,work_start `09:00`,work_end `17:00`,work_days `[0,1,2,3,4]`,duration_minutes `30`; admin can name/active. GET `/api/settings` `{business:{name:"Power Solar",timezone,market,privacy_contact,site_url},integrations:[...]}`. PATCH same business fields admin, disallow unsafe URLs. Integration statuses merged from channels.integration_status().
* GET `/api/appointments` -> `{appointments:[{id,lead_id,lead_name,advisor_id,advisor_name,start_at,end_at,status,source,created_at}]}`. POST `/api/appointments` `{lead_id,advisor_id,start_at}` confirm actual available slot, no overlap advisor OR same lead. PATCH `/api/appointments/{id}` `{status:"cancelled"}`. GET `/api/appointments/{id}/ics` calendar download with CRLF escaping. Auto-created confirmed appointment advances lead to cita.
* GET `/api/public/config` -> `{business:{name,timezone,market,privacy_contact,site_url},advisors:[{id,name}]}` active public-enabled only. GET `/api/public/slots?advisor_id=...&date=YYYY-MM-DD` -> `{slots:[{start_at,end_at}],timezone}` respect work days, future, buffers/24h horizon? minimum lead time 1h and maximum horizon 60 days. POST `/api/public/leads` `{name,email,phone,municipality,monthly_bill,consent:true,source,utm_source,utm_medium,utm_campaign,website:""}` -> `{lead_id}` no CRM PII leak. Source field canonicalized. POST `/api/public/book` same fields + advisor_id,start_at -> `{appointment:{id,start_at,end_at,advisor_name},message}` atomic lead + booking; validation rollback. Public no response PII or access to private records. consent required.
* GET `/api/conversations` -> `{conversations:[{id,channel,contact_name,lead_id,advisor_id,mode,last_message,updated_at}]}` scoped. GET `/api/conversations/{id}` -> `{conversation:...,messages:[{id,direction,text,status,created_at}]}`. POST `/api/conversations/{id}/mode` `{mode:"human"|"ai"}` -> conversation. POST `/api/conversations/{id}/messages` `{text}` real outbound via channels.send_message; log status sent/failed/uncertain, no fake sends. GET `/api/integrations` -> `{integrations:integration_status()}` admin only or scoped read no secrets. POST `/api/assistant/draft` `{lead_id?,prompt}` -> `{text}` actual AI only configured; no delivery.

## Connector/core boundary (both agents adhere)

Core includes tables `conversations(id TEXT PK, channel TEXT, external_id TEXT, contact_name TEXT, lead_id TEXT nullable FK leads, advisor_id TEXT nullable FK users, mode TEXT default 'human', updated_at TEXT, UNIQUE(channel,external_id))`, `messages(id TEXT PK, conversation_id TEXT FK, direction TEXT, text TEXT, status TEXT, external_id TEXT nullable, created_at TEXT, UNIQUE(conversation_id,external_id))`, `webhook_events(id TEXT PK,channel TEXT,status TEXT,created_at TEXT)`. IDs uuid hex; created_at UTC ISO. Core Store exposes `connect()` context manager connection row_factory=sqlite3.Row, foreign_keys on, commit on success rollback on exception; `settings()` dict business; `slots(advisor_id,date)` returns dict slots envelope; `book(data, source='web', actor=None)` data uses public/book schema; actor None public validation; `list_users()` list public-safe user objects. Connector can use Store.connect SQL for conversations/messages/events. Idempotency event claiming atomic, no automatic retries ambiguous outbound. Core router calls lazy `from .channels import register_routes, integration_status, send_message`; `register_routes(app)` inside create_app; `await send_message(channel, external_id, text)` returns `{status:"sent"|"failed"|"uncertain",provider_id?,error?}`. API logs returned outbound and returns 502 on failed, 504 on uncertain. `assistant.draft(prompt, business, history=None)` async -> str raises ValueError/RuntimeError if unconfigured/error. Core conversation mode initially human; never auto opt-in for unsolicited marketing. Channels router loads store via request.app.state.store. All channel inbound HMAC/secret validated, text messages only, limits, dedupe and opt-out; auto responses only when conversation explicitly mode=ai, inbound-driven; WhatsApp/Meta 24h user interaction window only. AI cannot invent successful booking. Supported paths `/webhooks/meta` GET/POST for WhatsApp/Messenger/Instagram and `/webhooks/telegram` POST. Reject absent configuration. Config secret names in `.env.example` root later based on connector report.
